🚀 QUICK START (13 minutes total)

STEP 1: Set Up Wallet (5 min)
  1. Install Metamask: https://metamask.io/
  2. Create wallet (or import existing)
  3. Export private key: Settings > Security & Privacy
  4. Get testnet MATIC: https://faucet.polygon.technology/

STEP 2: Update .env (2 min)
  Edit .env file:
  BLOCKCHAIN_NETWORK=polygon-mumbai
  WALLET_PRIVATE_KEY=0xYOUR_METAMASK_PRIVATE_KEY
  ENABLE_BLOCKCHAIN=true

STEP 3: Deploy Contract (3 min)
  npx hardhat run scripts/deploy-contract.js --network polygon-mumbai
  
  → Script auto-updates .env with FILEREGISTRY_ADDRESS

STEP 4: Start Server (1 min)
  npm start
  
  → Check health: curl http://localhost:3000/api/blockchain/health

STEP 5: Verify It Works (2 min)
  1. Upload file via web UI
  2. Check status: curl http://localhost:3000/api/blockchain/status
  3. View audit: curl http://localhost:3000/api/blockchain/user/history
